# Промпты для автоматизации ревью и доработки отчётов по учебной практике

Этот репозиторий содержит набор промптов для языковых моделей, которые помогают студентам готовить, проверять и дорабатывать отчёты по учебной практике (в формате `.tex`).

## Концепция: Разделение ролей
Вместо одного монолитного промпта, который пытается одновременно анализировать, писать и ревьюить, процесс разбит на три независимые роли. Это позволяет LLM фокусироваться на одной задаче и давать более качественный результат.

1. **Аналитик (`prompts/analyst.md`)** — собирает и анализирует уже существующие замечания (из pull requests, чатов, предыдущих итераций), формирует чек-лист требований и контекст для конкретной работы.
2. **Ревьювер (`prompts/reviewer.md`)** — проверяет текст отчёта на соответствие общим правилам (пунктуация, верстка LaTeX, структура, логика, технические термины) и выдает список замечаний. **Важно:** ревьювер НЕ меняет текст, а только указывает на ошибки.
3. **Писатель (`prompts/writer.md`)** — получает исходный текст и список замечаний от ревьювера, после чего вносит правки и формирует итоговую версию отчёта.

## Как использовать (Пайплайн)
1. Запустите промпт **Аналитика** с текстом отчёта и ссылками на существующие замечания. На выходе получите структурированный список требований.
2. Передайте текст отчёта и вывод Аналитика в промпт **Ревьювера**. На выходе получите детальный список замечаний с указанием на конкретные места в `.tex` файле.
3. Передайте исходный текст отчёта и замечания Ревьювера в промпт **Писателя**. На выходе получите исправленную версию отчёта.

## Вклад и разработка
Репозиторий открыт для доработки. Если вы хотите улучшить промпты:
1. Форкните репозиторий.
2. Внесите изменения в соответствующий файл в папке `prompts/`.
3. Создайте Pull Request в ветку `main`.
