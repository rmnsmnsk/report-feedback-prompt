# Промпты для автоматизации ревью и доработки отчётов по учебной практике

Этот репозиторий содержит набор промптов для языковых моделей, которые помогают студентам готовить, проверять и дорабатывать отчёты по учебной практике (в формате `.tex`).

## Концепция: Разделение ролей

Вместо одного монолитного промпта, который пытается одновременно анализировать, писать и ревьюить, процесс разбит на три независимые роли. Это позволяет LLM фокусироваться на одной задаче и давать более качественный результат.

1. **Аналитик (`prompts/analyst-prompt.md`)** — смотрит Pull Request, собирает замечания преподавателя, превращает частные замечания в общие правила и обновляет файл `requirements.md`.
2. **Ревьювер (`prompts/reviewer-prompt.md`)** — получает на вход текст отчёта и **актуальный `requirements.md`**, проверяет отчёт строго по этим требованиям и выдаёт список замечаний. **Важно:** ревьювер НЕ меняет текст, а только указывает на ошибки.
3. **Писатель (`prompts/writer-prompt.md`)** — получает исходный `.tex` и список замечаний от ревьювера, вносит правки и формирует итоговую версию отчёта.

## Файл `requirements.md`

В корне репозитория лежит файл `requirements.md` — **живой документ**, единый источник истины по требованиям к отчёту. 

Этот файл обновляется Аналитиком каждый раз, когда в PR появляются новые замечания преподавателя. Так частные замечания к одному студенту превращаются в общие правила для всех. Ревьювер использует этот файл как чек-лист при проверке отчётов.

## Как использовать (Пайплайн)

**Шаг 1. Запуск Аналитика**  
Передайте в промпт `prompts/analyst.md`:
- текущий текст `requirements.md`;
- содержимое PR (комментарии преподавателя).

На выходе получите:
- обновлённый `requirements.md` (закоммитьте его в репозиторий);
- список структурных замечаний к отчёту.

**Шаг 2. Запуск Ревьювера**  
Передайте в промпт `prompts/reviewer.md`:
- актуальный `requirements.md`;
- текст отчёта студента (`.tex`).

На выходе получите детальный список замечаний с указанием на конкретные места в `.tex` файле.

**Шаг 3. Запуск Писателя**  
Передайте в промпт `prompts/writer.md`:
- исходный текст отчёта;
- замечания Ревьювера.

На выходе получите исправленную версию отчёта.

## Вклад и разработка

Репозиторий открыт для доработки. Если вы хотите улучшить промпты:
1. Клонируйте репозиторий.
2. Внесите изменения в соответствующий файл в папке `prompts/`.
3. Если меняются правила — обновите `requirements.md`.
4. Создайте Pull Request в ветку `main`.
